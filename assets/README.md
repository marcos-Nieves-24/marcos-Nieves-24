# Profile assets

These SVG assets were generated with [`pixel-profile`](https://github.com/TheMysteriousGhost/pixel-profile) at commit [`ce302ba5`](https://github.com/TheMysteriousGhost/pixel-profile/commit/ce302ba5b9f6c1c7f6ce21fdfd899bc09c897985), licensed under the MIT License.

## Regenerate

Use Python 3.8 or newer. The generator has no third-party dependencies.

```bash
python3 pixel_profile.py --config assets/profile.json --out assets
```

Run the command from the repository root with `pixel_profile.py` available locally. The checked-in SVGs are self-contained and do not load external fonts, scripts, or images.
